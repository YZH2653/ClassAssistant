# ClassAssistant 开发需求文档

- 文档版本：1.0
- 编写日期：2026-09-23
- 对应版本：v1.0.0.0

---

## 一、项目背景与目标

课堂上老师讲授内容转瞬即逝，学生边听边记容易遗漏知识点。本项目开发一款运行在 Windows 11 电脑上的**课堂助手软件（ClassAssistant）**，在上课时将老师的语音实时转写为文字，下课后自动总结本节课的知识点，帮助学生复习。

- 语音识别：调用**小米 MiMo v2.5 ASR**（云端 API）将语音转成文字
- 知识点总结：调用**小米 MiMo v2.6 flash**（云端 API）生成总结
- 目标机型：REDMI Book Pro 14 2024（Windows 11）

## 二、目标用户与运行环境

- **目标用户**：学生（软件可分发给多个使用者，每个使用者使用自己的 API 密钥）
- **操作系统**：Windows 11
- **硬件**：REDMI Book Pro 14 2024（自带麦克风），兼容一般 Windows 11 笔记本
- **运行依赖**：WebView2 运行时（Win11 一般自带）、网络（调用 MiMo 云端 API 时需要）

## 三、第一版功能范围（v1.0.0.0）

### 包含

1. 实时语音转文字（实时转写）
2. 下课自动总结知识点
3. 设置页面（使用者自行输入自己的 MiMo API 密钥与接口配置）

### 暂不做（已确认不做，登记备查）

- 导出功能（Markdown/TXT/DOCX 导出）
- 课程历史管理与全文搜索
- 暂停/继续录音、手动标记重点
- 多设备同步、多人协作
- 数据库（v1 用文件存储）
- 音频文件落盘保存
- **其他厂商 API/模型接入（当前仅支持小米 MiMo）**

## 四、核心用户流程

1. 首次启动 → 进入「设置」页填写自己的 MiMo API 密钥（ASR 与总结各一组）→ 保存
2. 上课前点击「开始上课」→ 软件开始采集麦克风声音并实时转写，界面滚动显示文字
3. 授课过程中持续实时转写（未定稿文字灰色显示，定稿句子正常显示）
4. 下课时点击「下课」→ 转写文稿立即落盘 → 自动调用 MiMo v2.6 flash 生成知识点总结
5. 总结完成后界面展示知识点总结，并落盘保存到本机数据目录
6. 可点击「打开数据目录」查看本节课的转写文稿与总结文件

## 五、功能需求

### 5.1 实时转写

- 开始上课后，采集麦克风音频（16kHz / 单声道 / s16le PCM），流式发送给 MiMo v2.5 ASR
- 实时显示识别结果：未定稿文本（partial）灰色显示，定稿句子追加到转写区
- 转写文本自动滚动到最新位置
- 转写过程分段落盘，异常退出不丢失已有转写
- 识别出错时提示错误信息，尽量保留已转写内容

### 5.2 下课自动总结

- 点击「下课」后自动触发，无需额外操作
- 将本节课完整转写文本提交给 MiMo v2.6 flash，生成结构化知识点总结（Markdown），包含：
  - 知识点
  - 重点与难点
  - 课堂例题
  - 课后待办
- 总结生成过程中显示进度提示
- 总结完成后面板展示，并保存为 `summary.md`
- 总结失败时转写文稿仍然保留，可重试

### 5.3 设置页面（API 配置）

- **每位使用者输入自己的 MiMo API 密钥，程序不内置任何密钥**
- 目前仅支持小米 MiMo API（界面文案注明）
- 配置项（ASR 与总结两组，相互独立）：
  - API Key（密码框显示，可切换明文）
  - API Base URL（带默认值，可修改）
  - 模型名（默认 `mimo-v2.5-asr` / `mimo-v2.6-flash`，可修改）
- 提供「测试连接」按钮（ASR/总结各一），显示成功/失败提示
- 「保存」写入本机配置文件；「恢复默认」清空密钥并还原默认值
- 配置仅存本机，不入库（git）、不上传任何服务器
- 未配置密钥时点击「开始上课」→ 拦截并引导进入设置页

## 六、非功能需求

- **可靠性**：长课（2 小时以上）转写不丢稿；总结失败不影响已保存的转写
- **隐私与安全**：音频与文稿数据仅存本机；API 密钥仅本机保存，日志与错误信息中脱敏显示，不进代码仓库
- **性能**：实时转写延迟尽量低（说话后 1–2 秒内出字）；界面操作流畅不卡顿
- **存储**：纯本地文件存储，每节课一个会话目录；UTF-8 无 BOM 编码
- **兼容性**：Windows 11 中文环境正常显示，无乱码

## 七、验收标准

1. 填写 API 配置后重启软件配置仍生效；未配置时无法开课并有引导提示
2. 开始上课后能实时看到转写文字滚动更新
3. 下课后自动出现知识点总结（四段结构），并已保存到数据目录
4. 数据目录中每节课包含 `meta.json`、`transcript.md`、`summary.md` 三个文件，内容正确
5. 连续多节课互不覆盖，历史会话文件保持不变
6. 按钮状态互斥正确（录音中不能重复开课、空闲不能下课等）
7. Mock 模式下全流程可跑通（无需真实密钥）；`cargo test` 全绿
